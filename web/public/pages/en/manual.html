User Guide to DL4DH Feeder

This guide describes working with the DL4DH Feeder interface: navigating the interface, searching and filtering, viewing documents, exporting data, and submitting enrichment requests.

Home screen

The home screen offers simple searching across the documents and data contained in the connected Kramerius digital library.

Searching from the home screen

  • Searching is performed via the search bar in the centre of the screen.
  • Entered terms are searched in document titles, their full texts, and metadata.
  • The search bar includes an autocomplete feature that suggests available titles by name.
  • The "Public only" checkbox limits the search to so-called works in the public domain.

Entering without a search

The contents of the Feeder can also simply be browsed, for example using the prepared filters. In that case the search bar is left empty and entry is provided by the "Enter DL4DH Feeder" button.

Menu in the top right corner

The top right corner of the home screen contains a menu for:

  • switching the user interface to Czech,
  • displaying information about the project,
  • proceeding to the login page.

The login page lists the organisations whose institutional account can be used to log in.

💡 Logging in is recommended for full use of the Feeder. A logged-in user gains access to a larger set of features, including data export, as well as to a query history, which makes it possible to find out whether any change has occurred in the Feeder settings or in the underlying data since the last session.

Search interface

After entering the DL4DH Feeder, the search results screen is displayed. If no term was entered, the entire contents of the Feeder are available here and can be browsed using filters.

The screen has three main parts:

  • the search field at the top,
  • the left filter panel,
  • the main area with the list of found publications.

Search field

  • Serves for searching documents through full-text search and search in metadata.
  • Enables searching for documents containing recognized entities identified during enrichment (persons, geographic names, institutions, etc.).
  • While typing, the autocomplete suggests values relevant to the currently filtered set of documents.

Advanced search

Makes it possible to construct a more complex query that combines:

  • multiple searched attributes,
  • logical operators,
  • wildcard characters.

Filters in the left panel

The filters in the left panel serve to refine the results. The panel consists of two parts.

Grey part: metadata and availability

Filters documents by data taken from the bibliographic records of the library system:

  • document availability (access status),
  • document type (books, newspapers and magazines, sheet music…),
  • keywords,
  • authors,
  • geographic names.

Blue part: recognized entities (NameTag)

Makes it possible to search within the named entities recognized during enrichment:

  • institutions,
  • geographic names,
  • personal names,
  • addresses, etc.

⚠️ These filters work only for enriched publications.

💡 The Search NameTag field serves to narrow down the offered values.

Working with filters

  • Active filters are placed at the top of the left column.
  • A filter can be removed by clicking the specific filter.
  • The list of publications in the main area responds to the combination of the query and the applied filters.
  • Sorting of results is possible by relevance, date of publication, or alphabetically (by title, author, etc.).

Display of results

Display format

  • Cards (default): basic bibliographic information and a preview page of the document.
  • List view.
  • Graph: for the chart, the values plotted on the horizontal axis can be selected.

Switching between formats is available in the screen header.

Display level

  • by whole publications,
  • by individual pages containing the searched term or concept.

Pagination

Only a limited number of results is displayed on a single screen. The arrows in the bottom right corner lead to the rest.

Saving a search query

A search query can be saved by clicking the floppy disk icon next to the search field. Saved queries are then available in the user profile.

Viewing documents

The details of a document and its image data are displayed after clicking the desired document in the search results.

Left panel of the document

  • Contains a list of the document's pages and, above it, a search bar for searching the full text.
  • Serves to switch between searching within the document and document details.
  • The left column can be hidden by clicking the protruding field with the arrow on the right.

Working with the document

  • The document can be printed, shared, or downloaded, including the related metadata.
  • Hovering the cursor over the bottom of the screen reveals a menu of additional options:
  • zooming in and out,
  • rotating the page,
  • expanding the page to full screen.

Ways of displaying the content

The presentation part of the web page also offers other ways of displaying the content:

  • two consecutive pages of the same document in image form,
  • or the recognized text,
  • a combination of the page image and the recognized text on the same page.

Comparison mode

The right part of the screen can be switched to comparison mode in order to view two documents side by side. During parallel viewing, the details of the second publication are located on the right side.

Data export

The found publications, or their selected pages, can be exported and downloaded to the researcher's device for further processing.

⚠️ The user must be logged in in order to export data.

Selecting publications for export

The Export/Request button in the top right part of the search screen serves for export.

After it is pressed, the publications to be exported are selected. For faster selection, buttons are available below the search field:

  • select all documents displayed in the search in bulk,
  • remove all documents currently displayed in the search,
  • deselect all selected documents.

⚠️ When the option "select all currently displayed documents" is chosen, only the documents currently visible in the search are included in the export. If the results continue on a further screen, they must be selected separately.

Export settings

After the Export publications button is pressed, a dialog opens for choosing:

  • the target format of the export (TEXT, CSV/TSV, JSON, TEI, or ALTO),
  • the parameters, which differ in part for individual formats.

If the exported parts are not restricted, the exported data contains the maximum of data, metadata, and paradata obtained both from the original digital library and during the enrichment process.

⚠️ The listed formats are available for enriched publications. Publications that have not undergone enrichment can be exported only in the ALTO XML and TXT formats.

If the required document has not yet been processed, an [[#Enrichment request]] can be submitted through the Feeder.

Downloading the export

The data export is scheduled and, once completed, is available for download as a .zip file. The user is informed about the progress of the export and about the download link in their account, in the Exports tab.

Enrichment request

The Export/Request button serves for creating an enrichment request.

The selection of publications for enrichment proceeds by the same mechanism as for export. This is followed by pressing the "New request" button.

In the displayed dialog window, the Enrichment option remains checked. The request may include:

  • a message explaining why the publications should be enriched and for which project,
  • an attached PDF.

The request is handled by the digital library curator, who informs about its status by the e-mail associated with the account the user is logged in to. The status of requests is also visible in the user profile.

User profile

The name of the logged-in user functions as a hub for tracking individual features.

Exports tab

Contains an overview of all export jobs the user has started in the system. For exports that have completed successfully, the results can be downloaded. The table shows:

  • the export name,
  • the date of creation,
  • the status,
  • the export format,
  • details,
  • the download link (which can be used repeatedly).

Requests tab

Contains a list of the enrichment requests the user has submitted and the status of their processing. After clicking an individual request, the entered enrichment context (the message) and the included publications are also visible.

Request history tab

Contains a list of saved search queries. For each query the following is recorded:

  • the query name,
  • the applied filters,
  • the number of results,
  • the date of saving.

The buttons on the right side of each row make it possible to:

  • copy the query URL to the clipboard,
  • go directly to the search query,
  • delete the query.

💡 When proceeding to a saved search query, a notification is displayed if the number of results has changed since the query was saved (for example, because new documents matching the query have been added to the digital library).
